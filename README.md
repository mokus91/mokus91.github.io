# Global Support Radar

This repository publishes the Global Support Radar website at https://mokus91.github.io/.

The published files are synchronized from https://github.com/mokus91/global-support-radar by the GitHub Pages deployment workflow. The workflow is intended to run after source changes and on an hourly schedule.

## Public-service policy

Global Support Radar is free for every visitor. The public website has no advertising, paid features, subscriptions, sponsored ranking, affiliate offers, or payment flow. Search, filters, language pages, and links to official sources are free to use.

The site is an independent information directory, not a government agency or eligibility decision-maker. Visitors must verify deadlines, requirements, and current status with the original official source.

## Publishing

The source of truth is the `global-support-radar` repository. The live site is published at the root domain, with the sitemap and robots file at:

- https://mokus91.github.io/sitemap.xml
- https://mokus91.github.io/robots.txt

No AdSense verification or advertising resources are required for the current free, ad-free model.
