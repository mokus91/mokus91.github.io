# Global Support Radar

This repository publishes the Global Support Radar website at https://mokus91.github.io/.

The published files are synchronized automatically from https://github.com/mokus91/global-support-radar by the GitHub Pages deployment workflow. The workflow runs after changes to this repository and on an hourly schedule.

The live site uses the root-domain sitemap at https://mokus91.github.io/sitemap.xml and robots.txt at https://mokus91.github.io/robots.txt.

AdSense verification resources are published at the root domain: /ads.txt, with the site verification code included in the localized landing pages.
